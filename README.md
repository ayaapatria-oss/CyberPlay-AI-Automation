## Description
CyberPlay AI Automation is a system automation project using shell scripting and CI/CD pipeline for monitoring system performance and network status.

## Features
- CPU Monitoring
- Memory Monitoring
- Network Monitoring
- Automation Logging
- CI/CD Pipeline with GitHub Actions

## Pipeline Environments
- Staging
- UAT
- Production
